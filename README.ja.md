# 筆跡診断および心理プロファイリングシステム

## 概要
このアプリケーションは、コンピュータビジョンと大規模言語モデル（LLM）を活用して、アップロードされた画像から筆跡の特徴を分析します。傾斜、筆圧、間隔などの特徴を抽出することで、Mistral AI APIを利用してPDF形式の包括的な心理レポート（筆跡学）を生成します。

## 注意事項：本システムは、英語、スペイン語、フランス語などのラテン文字体系のみを分析可能です。

## 技術スタック
- **バックエンド**: Flask (Python)
- **AIエンジン**: Mistral AI (mistral-large-latest)
- **PDF生成**: FPDF
- **画像処理**: カスタム処理ロジック（utilsを参照）

## 主な機能
- **自動特徴抽出**: アップロードされた画像を処理し、ループの多様性、ガーランドのスタイル、ベースラインの角度など、9つの特定の筆跡特徴を特定します。
- **LLMによる分析**: Mistral AIを介した構造化されたプロンプトエンジニアリングを使用して、生データを自然言語による心理プロファイルに解釈します。
- **矛盾の解決**: AIエージェントは、相反する特徴（例：高い調整能力と一時的な情緒不安定さの両立など）を特定し、説明するように指示されています。
- **パーソナライズされたレポート**: 提出時に入力された対象者の名前に合わせて、プロフェッショナルなPDFレポートを生成します。

## インストールとセットアップ

### 前提条件
- Python 3.8 以上
- Mistral AI API キー

### インストール手順
1. ローカルマシンにリポジトリをクローンします。
2. 仮想環境を作成し、有効化します：
   ```bash
   python -m venv venv
   source venv/bin/activate  # Windowsの場合: venv\Scripts\activate
   ```
3. 依存関係をインストールします：
   ```bash
   pip install -r requirements.txt
   ```

### 設定
ルートディレクトリに `.env` ファイルを作成するか、`constants.py` を更新してAPI認証情報を設定してください。アプリケーションを実行する前に、`uploads/` および `app/reports/` ディレクトリが存在することを確認してください。

## 使用方法
1. Flaskサーバーを起動します：
   ```bash
   python run.py
   ```
2. Webブラウザで `http://127.0.0.1:5000` にアクセスします。
3. 対象者の名前を入力し、筆跡の鮮明な画像をアップロードします。
4. 生成されたPDF心理レポートをダウンロードします。
